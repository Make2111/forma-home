# Маке Нуреке — автосалон

Адаптивная промо-страница автосалона с каталогом демонстрационных автомобилей, поиском, фильтрами по кузову, сортировкой, карточками автомобилей и формами заявок.

## Запуск

Откройте `index.html` в браузере. Фотографии загружаются из Unsplash, шрифт — из Google Fonts.

## Перед публикацией для клиентов

- Замените демонстрационные автомобили и цены на актуальные предложения.
- Укажите реальные адрес, телефон и график работы.
- Подключите формы заявок к CRM, почте или мессенджеру.
